# Platform snapshot

**Date of this snapshot: 22 November 2026 (Europe/London).**

This page holds the YouTube facts that move: limits, eligibility, thresholds and metric names. **Refresh it quarterly**, by the maintainer, and add a line to [CHANGELOG.md](https://github.com/brenotreviso/channel-practice/blob/main/CHANGELOG.md). **Refresh it again after 1 February 2027**, when announced YPP changes take effect: recheck every YPP row below and [chapter 11](11-partner-program.md).

## How to refresh (for the maintainer)

1. Re-open every official URL in the table below.
2. Update any number, name or eligibility rule that has changed, and the date at the top.
3. Search the chapters for the old value and update them too.
4. Add a CHANGELOG line.
