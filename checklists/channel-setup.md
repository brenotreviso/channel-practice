# Channel setup

Do this once. See [chapter 2](../docs/02-channel-setup.md).

- [ ] Channel created, as a personal or Brand Account channel ([YouTube Help](https://support.google.com/youtube/answer/1646861?hl=en))
- [ ] Picture, name and handle chosen
- [ ] Phone number verified, so custom thumbnails and videos over 15 minutes are unlocked ([feature access](https://support.google.com/youtube/answer/9890437?hl=en))
- [ ] Checked **Settings → Channel → Feature eligibility** and noted whether advanced features are on
- [ ] Two-line channel description written: who it is for, what they get
- [ ] Audience (made for kids) answered honestly ([YouTube Help](https://support.google.com/youtube/answer/9528076?hl=en))
- [ ] I know when I would need to tick “altered or synthetic content” ([YouTube Help](https://support.google.com/youtube/answer/14328491?hl=en))
- [ ] Comment settings chosen ([YouTube Help](https://support.google.com/youtube/answer/9483359?hl=en))
- [ ] I did **not** spend the evening on a banner, logo or trailer
