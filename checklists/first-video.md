# First video

The 7-day path from [chapter 0](../docs/00-start-here.md), as boxes.

- [ ] Day 1: channel created; phone verified; two-line description
- [ ] Day 2: viewer, question and learner outcome written
- [ ] Day 3: 4–6 minute script written and read aloud; answer starts within 30 seconds
- [ ] Day 4: filmed horizontally, sound close; 3–4 thumbnail stills; one vertical clip
- [ ] Day 5: edited; title, thumbnail, description, audience setting; [title and thumbnail checklist](title-and-thumbnail.md) and [before you upload](before-you-upload.md) ticked; published
- [ ] Day 6: one Short uploaded; related video added if available; comments answered
- [ ] Day 7: [48-hour review](review-48h.md) done; one next video written in a sentence
- [ ] I did not delete anything
